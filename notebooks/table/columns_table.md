# Описание табличного датасета

| № | Колонка | Заключение | Обоснование |
| --- | --------- | ------------ | ------------- |
| 1 | Код пациента | Нельзя использовать | Уникальный идентификатор, не несет прогностической информации, приведет к переобучению. |
| 2 | Name | Нельзя использовать | Имя пациента, технический/идентифицирующий признак, не влияет на исход. |
| 3 | Age | Можно использовать | Возраст пациента, важный демографический предиктор, известен на момент прогноза. |
| 4 | Sex | Можно использовать | Пол пациента, важный признак. |
| 5 | Наличие в БД | Нельзя использовать | Технический признак наличия записи в базе данных, не относится к состоянию пациента. |
| 6 | Наличие в файле | Нельзя использовать | Технический признак наличия в каком-либо файле, не имеет прогностической ценности. |
| 7 | STEMI | Можно использовать | Наличие инфаркта миокарда с подъемом сегмента ST, известно на момент поступления. |
| 8 | ЧКВ | Можно использовать (с осторожностью) | Факт проведения чрескожного коронарного вмешательства может быть решением, принятым после поступления. Однако если модель предсказывает смерть при поступлении до проведения ЧКВ, то факт будущего ЧКВ неизвестен и является утечкой. Рекомендуется не использовать в модели, предсказывающей исход при поступлении. Если модель прогнозирует смерть после ЧКВ, то можно, но тогда момент прогноза сдвигается. Для стандартной задачи бинарной классификации смерти в стационаре по данным при поступлении – Data Leak. |
| 9 | Дата STEMI | Нельзя использовать | Дата события в прошлом может быть полезна как давность (разница с датой поступления), но сама абсолютная дата не информативна и может привести к утечке временных закономерностей. Лучше заменить на производный признак "время от начала симптомов до поступления". В исходном виде – не рекомендуется. |
| 10 | Вид STEMI | Можно использовать | Передний/нижний и т.п., известно при поступлении. |
| 11 | SYNTAX Score | Можно использовать (с осторожностью) | Оценка тяжести поражения коронарных артерий, рассчитывается по данным коронарографии. Если ангиография выполняется после поступления, то признак неизвестен в момент первого прогноза. Однако во многих клинических моделях риск стратифицируют после ангиографии. В зависимости от постановки задачи (прогноз после получения всех диагностических данных) может быть допустим. Для строгого избежания утечки – если ангиография проводится после решения о госпитализации, то признак недоступен в нулевой момент времени. Рекомендуется использовать, если модель имитирует прогноз после выполнения ангиографии. |
| 12 | Инфаркт-зависимая артерия | Можно использовать (с осторожностью) | Аналогично SYNTAX Score, определяется при ангиографии. Если модель строится на данных, доступных после диагностической коронарографии, допустимо. |
