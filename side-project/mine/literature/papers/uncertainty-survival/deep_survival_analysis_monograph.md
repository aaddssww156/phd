## Аннотация

Many applications involve reasoning about time durations before a critical event happens. This monograph provides a self-contained modern introduction to survival analysis, from Cox proportional hazards to neural ODE models. Covers competing risks, dynamic prediction, and time-varying covariates. Includes accompanying code repository.
