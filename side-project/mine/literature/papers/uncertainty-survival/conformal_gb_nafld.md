# Conformal Risk Prediction for NAFLD Using Gradient Boosting with Distribution-Free Coverages

## Аннотация

We present a ML framework coupling gradient-boosted decision trees with conformal prediction to yield calibrated, distribution-free coverage guarantees on individual risk estimates. Integrates mutual-information-based stability selection via bootstrap resampling for compact, clinically interpretable feature subset.

ИДЕАЛЬНЫЙ РЕЦЕПТ: gradient boosting + conformal prediction + stability selection. Практически твой техностек с добавлением conformal.
