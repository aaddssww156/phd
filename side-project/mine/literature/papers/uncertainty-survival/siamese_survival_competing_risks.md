# Siamese Survival Analysis with Competing Risks

## Аннотация

Survival analysis in the presence of multiple possible adverse events (competing risks) is a pervasive problem in healthcare. Since only one event is typically observed, the incidence of one type of event hinders the occurrence of others. Siamese networks for different event types.

---

## Релевантность проекту

В реанимации: КШ vs смерть от другой причины vs выписка — competing risks. Бинарная классификация это игнорирует.
