# Continuous-Time Linear Positional Embedding for Irregular Time Series Forecasting

**Авторы:** Kim B., Lee J.G.

## Аннотация

Irregularly sampled time series forecasting is prevalent in practical applications. To extend transformers to handle irregular time series, we propose CTLPE, learning a continuous linear function for encoding temporal information. The two challenges — inconsistent observation patterns and irregular time gaps — are solved by learning a continuous-time function and concise position representation.

## Релевантность проекту

Если добавишь Transformer для временных рядов (ЧСС, SpO2), CTLPE — SOTA позиционное кодирование для нерегулярных измерений.
