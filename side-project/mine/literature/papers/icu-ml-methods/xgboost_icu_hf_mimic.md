# Optimizing Mortality Prediction for ICU Heart Failure Patients: Leveraging XGBoost and Advanced Machine Learning with the MIMIC-III Database

**Авторы:** Ashrafi N., Abdollahi A., Zhang J., Pishgar M.

**Дата:** 2024-09-03 | **arXiv:** [2409.01685](https://arxiv.org/abs/2409.01685) | **PDF:** [Скачать](https://arxiv.org/pdf/2409.01685)

---

## Аннотация

Heart failure affects millions of people worldwide. This study analyzed data from 1,177 patients from MIMIC-III. Through rigorous feature selection using VIF, expert clinical input, and ablation studies, 46 key features were identified. XGBoost emerged as the superior model, achieving a test AUC-ROC of 0.9228, significantly outperforming previous work. SHAP analysis highlighted key variables like leucocyte count and RDW.

---

## Релевантность проекту

Идентичная методология: XGBoost + SHAP + Grid-Search. VIF feature selection (можно применить у себя). AUROC 0.92 — сильный baseline.
