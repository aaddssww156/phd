# Data-Driven Machine Learning Approaches for Predicting In-Hospital Sepsis Mortality

**Авторы:** Shumilov A., Zhu Y., Ashrafi N., Abdollahi A., Placencia G., Alaei K., Pishgar M.

## Аннотация

Sepsis is a severe condition responsible for many deaths. Using ICU patient records from MIMIC-III, we extracted relevant data through literature review and clinical input to develop an interpretable and accurate ML model to predict in-hospital sepsis mortality.
