# EHR-RAGp: Retrieval-Augmented Prototype-Guided Foundation Model for Electronic Health Records

**Авторы:** Shurrab S., Al-Omari M., El Samad D., Shamout F.E.

**Дата:** 2026-05-12 | **arXiv:** [2605.12335](https://arxiv.org/abs/2605.12335) | **PDF:** [Скачать](https://arxiv.org/pdf/2605.12335)

## Аннотация

EHR contain rich longitudinal patient information. EHR-RAGp is a retrieval-augmented foundation model that dynamically integrates the most relevant patient history across diverse clinical event types via prototype-guided retrieval. Consistently outperforms SOTA EHR foundation models and transformer baselines.

---

## Релевантность проекту

Cutting-edge (май 2026): foundation model + RAG для EHR. Модель сама решает, какие эпизоды истории важны для предсказания.
