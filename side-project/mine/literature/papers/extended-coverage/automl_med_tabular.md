# AutoML-Med: A Framework for Automated Machine Learning in Medical Tabular Data

**Авторы:** Francia R., Leone M., Leonardi G., Montani S., Pennisi M., Striani M., D'Alfonso S.

## Аннотация

Medical datasets are affected by missing values, class imbalance, heterogeneous feature types, and high dimensionality vs small sample size. AutoML-Med identifies the optimal combination of preprocessing techniques and predictive models via Latin Hypercube Sampling, minimizing user intervention.

---

## Релевантность проекту

Твой ручной pipeline (MICE + scaling + 5 моделей + Optuna) можно сравнить с AutoML baseline. Близко к CliMB.

---

## Методологические заметки

Latin Hypercube Sampling, automated preprocessing + model selection, medical-specific
