# FLICU: A Federated Learning Workflow for Intensive Care Unit Mortality Prediction

**Авторы:** Mondrejevski L., Miliou I., Montanino A., Pitts D., Hollmen J., Papapetrou P.

**Дата:** 2022-05-30 | **arXiv:** [2205.15104](https://arxiv.org/abs/2205.15104) | **PDF:** [Скачать](https://arxiv.org/pdf/2205.15104)

---

## Аннотация

Healthcare data is sensitive, requiring strict privacy practices, and typically stored in data silos. Federated learning can train ML models over data silos while keeping sensitive data localized. FLICU proposes a federated learning workflow for ICU mortality prediction.

---

## Релевантность проекту

Если данные из нескольких клиник нельзя объединить — FL позволяет обучаться на всех данных без их перемещения.
