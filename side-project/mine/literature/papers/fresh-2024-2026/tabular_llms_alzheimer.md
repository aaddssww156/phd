# Tabular LLMs for Interpretable Few-Shot Alzheimer's Disease Prediction with Multimodal Biomedical Data

**Авторы:** Kearney S., Yang S., Wen Z., Lyu W., Hou B., Duong-Tran D., Chen T., Moore J.H., Ritchie M.D., Chen C., Shen L.

## Аннотация

We propose TAP-GPT, a domain-adapted tabular LLM framework built on TableGPT2 and fine-tuned for few-shot AD classification using tabular prompts. LLMs offer few-shot generalization, structured reasoning, and interpretable outputs for clinical prediction.

---

## Релевантность проекту

LLM для табличных клинических данных — растущий тренд 2026. Few-shot clinical prediction с интерпретируемыми output.
