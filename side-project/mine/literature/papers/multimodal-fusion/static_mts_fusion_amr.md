# Multimodal Interpretable Data-Driven Models for Early Prediction of Antimicrobial Multidrug Resistance Using Multivariate Time-Series

## Аннотация

EHR is an inherently multimodal register characterized by static data and multivariate time series (MTS). While MTS are valuable for clinical prediction, fusion with other modalities can result in more thorough insights. We present an interpretable multimodal data-driven model combining static data and MTS.
