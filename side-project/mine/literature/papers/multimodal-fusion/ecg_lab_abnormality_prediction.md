# Abnormality Prediction and Forecasting of Laboratory Values from ECG Signals Using Multimodal Deep Learning

**Авторы:** Lopez Alcaraz J.M., Strodthoff N.

**Дата:** 2024-11-22 | **arXiv:** [2411.14886](https://arxiv.org/abs/2411.14886) | **PDF:** [Скачать](https://arxiv.org/pdf/2411.14886)

---

## Аннотация

This study investigates using ECG data combined with basic patient metadata to estimate laboratory abnormalities. Using MIMIC-IV, multimodal DL models on ECG waveforms, demographics, biometrics, and vital signs achieve AUROCs above 0.70 for 24 lab values across cardiac, renal, hematological, metabolic, and immunological panels.

---

## Релевантность проекту

S4 state-space для сигналов + late fusion для метаданных. Паттерн воспроизводим для «временные ряды + таблицы».

## Методологические заметки

S4 classifier, late fusion, 24 lab values, cardiac/renal/hematological panels
