# Enhancing Diagnostic Accuracy for Urinary Tract Disease through Explainable SHAP-Guided Feature Selection and Classification

**Авторы:** de Oliveira F.F., Rocha M.B., Krohling R.A.

**Дата:** 2025-10-22 | **arXiv:** [2510.19896](https://arxiv.org/abs/2510.19896) | **PDF:** [Скачать](https://arxiv.org/pdf/2510.19896)

## Аннотация

We propose SHAP-based feature selection to enhance transparency of predictive models. XGBoost, LightGBM, and CatBoost with Optuna hyperparameter optimization and SMOTE class balancing. SHAP guides variable selection for six binary classification scenarios.

---

## Релевантность проекту

ПРАКТИЧЕСКИ ТВОЙ ТЕХНОСТЕК: XGBoost + LightGBM + CatBoost + Optuna + SHAP. SHAP используется для feature selection (у тебя — экспертное наращивание).

## Методологические заметки
