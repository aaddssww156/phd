# Missingness as Stability: Understanding the Structure of Missingness in Longitudinal EHR Data

## Аннотация

There is an emerging trend in RL for healthcare: researchers resample time series to regular intervals and use LOCF imputation without maintaining information about which values were imputed. We propose an alternative representation that incorporates missingness information, yielding consistently better results for optimal control.
