# Closing Gaps: An Imputation Analysis of ICU Vital Signs

## Аннотация

As more ICU data becomes available, interest in clinical prediction models increases. However, lack of data quality still hinders clinical prediction using ML. Many vital sign measurements contain sizeable missing segments. Previous works introduced numerous time-series imputation techniques, but more comprehensive comparison on ICU data is needed.
